# Cómo revisar esta nueva versión

Este repositorio está reescrito alrededor de Sami y del equipo Renkay descritos en su repositorio anterior. La portada, la arquitectura y los diagramas son nuevos. La documentación principal está en inglés para la evaluación internacional; esta guía explica la entrega en español.

## Qué contiene

El README presenta el proyecto. docs/ desarrolla mecánica, electrónica, software, Open, Obstacle, decisiones, reproducción y pruebas. Cada explicación enlaza archivos reales. src/ contiene los paquetes del coach y sus tests; tools/ contiene las utilidades de instalación, arranque y calibración. Los comentarios chinos de los controladores se han traducido y el README del LiDAR conserva su versión inglesa. Se retiró la aplicación de menú para Mac y los ejercicios del curso de la estructura principal.

## Cómo leerlo

1. Abre README.md en GitHub o en la vista previa Markdown de VS Code.
2. Lee docs/04-open-challenge.md y docs/05-obstacle-challenge.md para comprender lo que ejecutan las estrategias.
3. Revisa docs/10-evidence-register.md: concentra lo que requiere comprobar el carro físico.
4. Completa primero la identificación del código instalado, el cableado, el CAD y las evidencias actuales. Las mediciones no se inventan.

## Antes de reemplazar lo que ya está en GitHub

Esta carpeta es una versión nueva independiente. No la copies encima de la anterior esperando que desaparezcan los archivos sobrantes: una copia agrega y reemplaza archivos, pero no elimina los viejos. Haz la integración en una copia de trabajo del repositorio existente, revisando qué archivos reemplazar o retirar y conservando la foto y los cambios propios. No uses force push ni fabriques historial. La publicación de esta versión todavía no se ha realizado.

La lista detallada de mejoras está en MEJORAS-Y-EVIDENCIAS.md. El repositorio explica el sistema con el material disponible; las fotos actuales, los ensayos y el CAD físico siguen dependiendo de archivos y mediciones reales del equipo.
