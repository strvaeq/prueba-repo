# Testing workflow

Record hardware revision, source commit, parameter profile, battery voltage, lighting, surface and field layout before each attempt. Test both directions, varying Open corridor widths, Obstacle arrangements, departure and parking. Include failures. Separate simulated and physical results. Report numerator/denominator, completion time and failure categories; never infer reliability from one successful video.

For each test: objective → controlled conditions → procedure → raw observations → metric → interpretation → next revision. Preserve video/log IDs and repeat the same procedure after changes.
