## Reference practices adopted in this edition

This is a documentation comparison, not a reproduced performance benchmark or a judge-commentary report. The user supplied team ranks and scores; no deduction is attributed to a specific repository feature without judges' comments. Each local reference checkout is identified by commit in [reference-snapshots.json](other/reference-snapshots.json).

| Reference | Concrete practice visible in its documentation | Application here |
|---|---|---|
| [Double X](https://github.com/ejm22/WRO-FE-XX) | Hardware architecture, battery-side/load-side reasoning, image pipeline and linked algorithm details | Rail-based budget method, source-linked strategy explanations and measured-versus-requested distinctions |
| [KMIDS GFM](https://github.com/Chayanon-Ninyawee/KMIDS-GFM-Future-Engineer-2025) | Editable CAD, STL/slicer categories, assembly and compilation routes | Manufacturing index and ordered reconstruction guide |

| [JEEP](https://github.com/batstateu-is/2025-BatstateU-IS) | Dated updates linked to real-field adjustments | Revision-aware deployment and test records |
| [VizDrive](https://github.com/vd-wro/VD26) | Vehicle-version table, observed failures and calibration-data links | Decision history with cross-system failure analysis |
| [Fire On All Cylinders](https://github.com/kirkhu/WRO2025_FE-Fire-On-All-Cylinders) | Separate learning/reading route and engineering overview | Short README route into detailed technical chapters |
